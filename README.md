# Juego de Probabilidades 🎲

Juego educativo para grado 5: observa cada situación, cuenta los objetos y escribe la
**fracción**, la **fracción simplificada** y el **porcentaje**.

**Jugar:** https://jalzate2020.github.io/probabilidades/

## Qué incluye

- 8 situaciones (bolitas, estrellas, carritos, fichas, dulces, figuras y pelotas).
- Botón **Pista** que guía paso a paso.
- Botón **¡Saca una al azar!** para comparar la probabilidad teórica con lo que pasa al sacar de verdad.
- **Reto sorpresa** con situaciones aleatorias al terminar.

## Desarrollo

Sitio estático sin dependencias. Abre `index.html` en el navegador.

```bash
npm test   # pruebas de la lógica (Node 18+)
```
